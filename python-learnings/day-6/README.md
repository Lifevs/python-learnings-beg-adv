# ⚪ Day 6: Environment Setup & Installation

Preparing the development foundation by establishing a proper Python environment.

## 🛠️ Featured Process: Windows Installation

The focus of Day 6 was navigating the official installation process to ensure a robust setup for future development.

### Key Steps:
1.  **Source Acquisition**: Downloading the correct installer from [python.org](https://python.org).
2.  **Installer Configuration**: Choosing the executable (`.exe`) approach.
3.  **PATH Integration**: The critical step of enabling "Add Python to PATH" for global terminal access.
