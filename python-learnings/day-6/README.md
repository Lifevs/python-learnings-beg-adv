# Day 6: Installing Python

Today I learned about the basic steps to install Python on Windows.

## Key Takeaways
- **Source**: Python can be downloaded from the official website: [python.org](https://python.org).
- **Installer**: For Windows, you typically download an executable (`.exe`) file.
- **Configuration**: It's important to check the **"Add Python to PATH"** checkbox during the installation process to ensure you can run Python from the command line easily.
