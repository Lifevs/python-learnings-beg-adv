# 🟤 Day 7: Interactive Scripting & Terminal Execution

Transitioning from writing static code to building functional terminal applications.

## 🛠️ Featured Project: Interactive Terminal Script

The `main.py` script demonstrates how to capture user input and provide dynamic feedback directly through the terminal interface.

### Key Concepts:
1.  **Capturing Input**: Using `input()` to pause execution and wait for user data.
2.  **Type Conversion**: Handling the string-default return of `input()` (e.g., converting to `int` or `float`).
3.  **Terminal Execution**: Mastering the `python main.py` command for local deployment.
