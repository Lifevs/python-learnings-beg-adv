# 🏁 Day 8: The Ultimate Python Basics Quiz

A comprehensive review of everything learned so far, from installation to interactive execution.

## 🛠️ Featured Activity: Knowledge Validation

Instead of a coding project, Day 8 focused on a multi-stage quiz designed to test foundational knowledge of the Python ecosystem, terminal usage, and the REPL environment.

### Core Topics Reviewed:
1.  **Ecosystem**: Identifying official sources and tools (python.org, IDEs).
2.  **Environment**: Understanding the terminal and PATH configurations.
3.  **Interactive Python**: Mastering the shell (REPL) and its unique syntax (`>>>`).
4.  **Execution**: Running scripts vs. interactive commands.

<details>
<summary><b>Q1: Where is the best place to download Python?</b></summary>

Always use the **official Python website** (python.org) to ensure you get the latest stable and secure version.

<details>
<summary><b>Q2: What is a terminal in the context of programming?</b></summary>

A **text-based interface** used for running commands and interacting with the operating system directly.
![Terminal Definition](Screenshot%202026-06-07%20at%2010.45.37 PM.png)
</details>

<details>
<summary><b>Q3: What does IDE stand for?</b></summary>

**Integrated Development Environment**—a software application that provides comprehensive facilities to computer programmers for software development.
![IDE Meaning](Screenshot%202026-06-07%20at%2010.45.42 PM.png)
</details>

<details>
<summary><b>Q4: Which are popular IDEs or code editors for Python?</b></summary>

**VS Code, PyCharm, and Spyder** are industry standards for Python development.
![Popular IDEs](Screenshot%202026-06-07%20at%2010.45.47 PM.png)
</details>

<details>
<summary><b>Q5: How do you typically run a Python file from the terminal?</b></summary>

By using the command `python filename.py` (e.g., `python main.py`).
![Running Scripts](Screenshot%202026-06-07%20at%2010.45.52 PM.png)
</details>

<details>
<summary><b>Q6: What is an interactive shell?</b></summary>

A program that lets you **type commands one at a time** and see the results immediately.
![Interactive Shell](Screenshot%202026-06-07%20at%2010.45.56 PM.png)
</details>

<details>
<summary><b>Q7: How do you start the Python interactive shell?</b></summary>

Simply type `python` (or `python3`) and press **Enter** in your terminal.
![Starting Shell](Screenshot%202026-06-07%20at%2010.46.01 PM.png)
</details>

<details>
<summary><b>Q8: What does the >>> symbol mean?</b></summary>

It indicates that Python is **waiting for user input** text in the interactive shell.
![Prompt Symbol](Screenshot%202026-06-07%20at%2010.46.23 PM.png)
</details>

<details>
<summary><b>Q9: What does REPL stand for?</b></summary>

**Read-Evaluate-Print Loop**—the standard cycle of an interactive programming environment.
![REPL Meaning](Screenshot%202026-06-07%20at%2010.47.53 PM.png)
</details>

<details>
<summary><b>Q10: What happens when you run a print command in the shell?</b></summary>

It immediately **prints the output** to the terminal on the next line.
![Print Result](Screenshot%202026-06-07%20at%2010.47.47 PM.png)
</details>
